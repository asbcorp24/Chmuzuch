# Chmuzuch

Новый высокотехнологичный сайт БПОУ «Чебоксарское музыкальное училище им. Ф. П. Павлова».

Источник контента для миграции: https://xn--g1ajvbu.xn--p1ai/

Архитектура нового сайта: динамическая CMS с иерархией разделов parent → child, специализированными сущностями (новости, события, отделения, преподаватели, коллективы, конкурсы, конференции, документы, медиа) и сохранением legacy-ID/URL для контроля миграции и 301-редиректов.

См. `docs/OLD_SITE_CONTENT_MAP.md`.
