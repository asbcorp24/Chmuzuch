# Технологическая основа Chmuzuch

Проект строится на том же технологическом фундаменте, что и `asbcorp24/scoolcreativind`, но как самостоятельный сайт училища.

## Backend
- PHP 8+
- Laravel 9
- собственные Controllers / Models / admin routes
- собственная CMS, без Filament

## Frontend
- Blade
- Vite 4
- Bootstrap 5.3
- Three.js 0.180
- @google/model-viewer 4
- WebGL / GLB/GLTF
- адаптивные desktop/tablet/mobile layouts

## Переносимые возможности школы
- 3D hero и интерактивные модели
- wireframe / bloom / scene controls
- media library
- новости и динамические страницы
- визуальное редактирование контента
- управляемые блоки главной
- SEO/sitemap/robots
- поиск
- документы
- формы и обратная связь
- cookie consent и ПД
- версия для слабовидящих
- собственная административная зона

## Специфика училища
- иерархические разделы parent → child
- отделения
- преподаватели
- специальности
- творческие коллективы
- афиша/концерты
- конкурсы
- конференции
- абитуриенту
- студенту
- ДШИ
- ЦДО
- общежитие
- сведения об образовательной организации
- RU/CV-ready content model

## Визуальное направление
Не копировать оформление школы буквально. Основа: академическая музыка + современная технология + чувашский культурный код. Чувашский орнамент использовать как геометрию, motion-pattern, декоративную сетку и элементы 3D-сцен, без перегрузки интерфейса.
