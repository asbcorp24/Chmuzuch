# Карта миграции старого сайта Чебоксарского музыкального училища

> Источник: https://xn--g1ajvbu.xn--p1ai/  
> Назначение: рабочая карта миграции в новый Chmuzuch.  
> Статус: базовая карта подтверждённой публичной структуры; далее дополняется автоматическим crawler-аудитом всех legacy URL, вложений и архивов.

## 1. Принципы миграции

- Старый сайт — источник контента, но не архитектуры нового приложения.
- Все обычные информационные разделы строятся как дерево `pages.parent_id`; глубина не ограничена.
- Новости, события, афиша, отделения, преподаватели, коллективы, конкурсы, конференции, курсы, документы, медиа и программы ДШИ — специализированные сущности.
- У каждой импортированной записи сохраняются `legacy_source`, `legacy_id`, `legacy_url`, `legacy_type`.
- Старые URL после запуска должны получать 301 на новые canonical URL.
- Вложенные PDF/DOC/XLS/изображения скачиваются локально, классифицируются и связываются с новой сущностью.
- Не переносить старые технические типы вроде `news-item` как бизнес-модель: на старом сайте ими представлены даже обычные страницы.
- RU/CV закладываются архитектурно как переводимые поля; EN можно добавить без смены схемы.

## 3. Отделения училища

Родитель: **Отделения училища**.

1. Гуманитарных, социально-экономических и общеобразовательных дисциплин
2. Общего фортепиано
3. Фортепиано
4. Народных инструментов
5. Оркестровых струнных инструментов
6. Духовых и ударных инструментов
7. Дирижёрско-хоровое
8. Вокального искусства
9. Теории музыки
10. Музыкальное искусство эстрады
11. Сольного и хорового народного пения

Новая сущность `departments`. Каждое отделение связывается с преподавателями, специальностями, коллективами, новостями, событиями, достижениями, фото, видео, аудио и документами.

## 4. Творческие коллективы

Родитель: **Творческие коллективы**.

- Оркестр народных инструментов
- Хор дирижёрско-хорового отделения
- Вокальные ансамбли «Cantabile», «Prestige», «Abilita»
- Симфонический оркестр
- Фольклорный ансамбль «Янтал»

Новая сущность `collectives`: руководитель, состав, история, репертуар, достижения, афиша, новости, media.

## 5. Конкурсы и конференции

Это не `pages`, а отдельные сущности `competitions` и `conferences`.

Конкурс:
- название, статус, даты;
- положение, программа, номинации;
- организаторы/жюри;
- заявка;
- результаты, дипломы;
- документы и media.

Конференция:
- название, учебный год, даты;
- тема, описание;
- положение, программа, заявка;
- материалы/сборники;
- результаты;
- документы и media.

Архив хранить по годам через поле `academic_year`, а не создавать вручную отдельные шаблоны года.

## 9. Таблица правил legacy → new

| Старый тип/признак | Новый тип | Действие |
|---|---|---|
| Главная | landing | собрать блоками CMS |
| news-items | listing/category | не копировать как страницу, строить выборкой |
| news-item с реальной новостью | news | импорт |
| news-item с обычной информацией | page | переклассифицировать |
| Афиша | events | импорт событий |
| Отделение | department | импорт отдельной сущностью |
| Коллектив | collective | импорт |
| Конкурс | competition | импорт |
| Конференция | conference | импорт |
| ДШИ программа | dshi_program | импорт |
| Курсы | course/page | классифицировать по содержимому |
| ООО/Сведения | page + regulatory category | сохранить официальную иерархию |
| PDF/DOC/XLS | document | скачать и привязать |
| фото | media | скачать оригинал, сохранить источник |
| видео/аудио | media/external_media | перенести связь |
| устаревшее | archive | не удалять автоматически |
| дубль | redirect/reference | выбрать canonical, сохранить legacy redirect |

## 11. Контроль полноты

Миграция считается законченной только когда:

1. каждый обнаруженный внутренний HTML URL классифицирован;
2. каждый файл-вложение учтён;
3. все parent-child связи восстановлены;
4. старые ID сохранены;
5. для каждого legacy URL определён новый URL или archive/ignore с причиной;
6. нет потерянных изображений/документов;
7. проверены битые ссылки;
8. созданы 301;
9. выполнено сравнение количества записей по каждому типу;
10. выборочно визуально сверены импортированные страницы.

## 12. Технологическая концепция нового сайта

Новый Chmuzuch не копирует визуал старого сайта. Он использует тот же современный подход, что и сайт музыкальной школы: адаптивный интерфейс, CMS, визуальный редактор, 3D/WebGL, интерактивные сцены, bloom/wireframe где уместно, медиатеку, современную афишу и богатые страницы отделений. Визуальный язык — академическая музыка + современная технология + деликатный чувашский орнамент/культурный код.
